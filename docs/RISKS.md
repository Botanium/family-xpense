# Family Xpense: Risks

Likelihood and impact are High, Medium or Low. "Tripwire" is the observation that tells us the risk has become real. Work package ids refer to [DELEGATION.md](DELEGATION.md).

## Top five

1. **R-02 A2UI packages are pre-1.0** and the server and phone are already on different core versions.
2. **R-06 Decisions API** is beta and reachable only over REST.
3. **R-13 Partner privacy** depends on a denormalised field staying correct.
4. **R-09 Arabic-script receipts** cannot be read on the phone.
5. **R-17 The model writes invalid or wrong surfaces**, and the Express syntax for drafts is unconfirmed.

## Things that are not risks any more

- **Version drift from the brief:** every listed version was confirmed as current on 2026-11-22.
- **TypeScript versus Dart backend:** the JS A2UI plugin is still on v0.9, so the Dart decision holds.
- **`liquid_glass_renderer`:** ruled out; no evaluation needed.
